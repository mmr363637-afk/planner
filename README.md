# برنامه‌ریز مطالعه (Study Planner)

اپلیکیشن شخصی برنامه‌ریزی و مطالعه برای دانشجویان (به‌ویژه پزشکی) — **کاملاً فارسی، RTL، Offline-first و قابل نصب روی اندروید به‌صورت PWA**.

## قابلیت‌ها

| بخش | امکانات |
|---|---|
| خانه | سلام + تاریخ شمسی، **جمله‌ی انگیزشی روز** (۱۵۴ جمله؛ هر روز یکی، بدون تکرار تا حدود ۵ ماه + دکمه‌ی «بعدی»)، پیشرفت امروز (Ring + Progress)، **تایمر شمارش معکوسِ زنده تا نزدیک‌ترین امتحان (روز/ساعت/دقیقه/ثانیه — اختیاری از تنظیمات)**، کارهای امروز (شروع/تکمیل/جابه‌جایی/حذف)، مرورهای امروز، Streak/XP/مجموع مطالعه/تحقق هفتگی، بنر «عقب افتاده‌ای؛ Replan؟» |
| برنامه › دروس | **افزودن درس دلخواه در کنار نمونه‌های پزشکی**؛ درس با رنگ و اولویت؛ مبحث با توضیح، حجم، زمان تخمینی، اولویت، سختی، وضعیت یادگیری؛ **۱۳ درس نمونه با ۲۹۷ مبحث پیشنهادی، با افزودنِ غیرتکراری در هر به‌روزرسانی** |
| برنامه › برنامه‌ها | Wizard چهارمرحله‌ای (هدف/بازه/ساعت روزانه → دروس و مباحث → روزهای هفته → پیش‌نمایش) + **Planning Engine** با فشرده‌سازی نسبی و تقسیم مباحث بلند بین روزها + Replan |
| برنامه › تقویم | نمای روز/هفته/ماه شمسی، نشانگر تسک و مرور هر روز، افزودن دستی مبحث به روز |
| مطالعه | تایمر آزاد و پومودورو (قابل تنظیم)، **مطالعه بدون درس (فقط ثبت زمان، در هر دو حالت)**، ادامه‌ی صحیح تایمر هنگام جابه‌جایی بین صفحات/بستن اپ (مبتنی بر timestamp)، ارزیابی یادگیری در پایان، ثبت زمان واقعی، **کارت سریعِ صداهای تمرکز** |
| امتحانات | تقویم شمسیِ امتحانات با نشانگر رنگی، **ساعت شروع هر امتحان (اختیاری)**، فهرست پیش‌رو/گذشته، **تایمر شمارش معکوسِ زنده**، یادآوری اعلانی روز قبل/روز امتحان/یک ساعت مانده |
| صداهای تمرکز | **White & Brown Noise با سنتزِ زنده‌ی Web Audio**: 🌧️ باران، ⛈️ رعد و برق، 🏞️ رودخانه، 🟤 نویز قهوه‌ایِ بم و یکنواخت — بی‌پایان و **بدون درزِ تکرار**، بدون فایل صوتی، آفلاین و بدون مصرف اینترنت؛ **میکس هم‌زمان هر چهار صدا با حجم مستقل**، ترکیب‌های آماده (طوفان/باران ملایم/کنار رودخانه/تمرکز بم/باران گرم/میکس کامل)، حجم کلی، و پخشِ سراسری که بین صفحه‌ها قطع نمی‌شود |
| مرورها | Spaced Repetition (۱/۳/۷/۱۴/۳۰ روز، قابل تنظیم) با تطبیق فاصله بر اساس عملکرد؛ بخش‌های عقب‌افتاده/امروز/آینده؛ انجام/عقب‌انداختن/«بلد نیستم» |
| آمار | امروز/هفته/ماه، تعداد جلسات، مباحث تکمیل‌شده، تحقق برنامه، Streak، نمودار ۷ روز اخیر، نمودار بر اساس درس (شامل گروه «مطالعه بدون درس»)، **دستاوردها (گروه‌بندی‌شده + نوار پیشرفت کلی + «دستاورد بعدی»)** |
| گیمیفیکیشن | XP، سطح (نوآموز → استاد)، **۵۰ دستاورد** در ۷ گروه (زمان، مباحث، مرور، نظم، تداوم، عادت‌ها، تجربه) |
| تنظیمات | تم روشن/تیره/سیستم، **گرافیک‌های ثابت، محو و سه‌بعدی متناسب با هر صفحه (قابل خاموش‌کردن)**، **تم رنگی دلخواه (۱۲ رنگ آماده + انتخاب هر رنگ دلخواه؛ کل اپ هماهنگ عوض می‌شود)**، پومودورو، فاصله‌ی مرورها، **کلیدهای تایمر امتحان (تایمر/نمایش ساعت/یادآوری یک ساعت مانده)**، **حجم کلی صداهای تمرکز + بازکردن میکسر**، اعلان‌ها (۵ نوع — **یادآور صبحگاهی با جمله‌ی انگیزشی همان روز**)، ساعت شروع/پایان روز، Backup/Restore (JSON)، حذف همه‌ی داده‌ها |

## اجرا

```bash
npm install
npm run dev        # توسعه
npm test           # تست‌ها (Planning Engine, SRS, Streak, Progress, Study time, Jalali, Exam timer, White/Brown-noise engine, sample import/migration, subject-free study, page backgrounds, PWA assets, UI smoke)
npm run build      # خروجی در docs/ (همان پوشه‌ای که GitHub Pages منتشر می‌کند)
npm run preview    # سرو خروجی ساخته‌شده
```

## نصب روی اندروید

1. `docs/` را روی هر هاست HTTPS قرار دهید (یا `npm run preview` روی شبکه محلی).
2. در Chrome اندروید آدرس را باز کنید → منو → **«افزودن به صفحه اصلی» / Install app**.
3. اپ به‌صورت standalone (بدون نوار مرورگر) و آفلاین اجرا می‌شود؛ داده‌ها روی دستگاه ذخیره می‌شوند.

> برای تولید APK از همین کد می‌توان از **Bubblewrap / Trusted Web Activity** یا **Capacitor** استفاده کرد (نیازمند JDK + Android SDK).

## استقرار روی GitHub Pages

این پروژه یک اپ Vite است و **کد مبدأ مستقیماً در مرورگر اجرا نمی‌شود**؛ GitHub Pages فقط فایل
استاتیک سرو می‌کند، پس حتماً باید خروجی `npm run build` (پوشه‌ی `docs/`) منتشر شود. در غیر این
صورت صفحه سفید می‌ماند، چون `index.html` ریشه به `/src/main.tsx` (فایل TypeScript) اشاره می‌کند.

`vite.config.ts` خروجی build را در `docs/` می‌سازد و این پوشه **همراه ریپو commit می‌شود**؛ Pages
با حالت «Deploy from a branch» (شاخه‌ی `main`، پوشه‌ی `/docs`) همان را سرو می‌کند. بنابراین بعد از
هر تغییر در `src/`، این دو کار لازم است:

```bash
npm test && npm run build   # docs/ را از نو می‌سازد
git add docs && git commit  # خروجی جدید باید commit شود
```

(اختیاری) اگر ترجیح می‌دهید خروجی را commit نکنید، می‌توانید استقرار را به GitHub Actions بسپارید:
هر push روی `main` → نصب وابستگی‌ها → اجرای تست‌ها → `npm run build` → انتشار `docs/` روی Pages.

یک‌بار (تنظیم اولیه برای حالت Actions):

1. فایل `deploy-workflow.yml` (در ریشه‌ی ریپو) را به مسیر `.github/workflows/deploy.yml` منتقل کنید
   (در GitHub: **Add file → Create new file**، مسیر را `.github/workflows/deploy.yml` بگذارید و
   محتوای همان فایل را paste کنید). این فایل در ریشه نگه داشته شده چون توکن دسترسی این محیط اجازه‌ی
   ساخت فایل workflow را ندارد.
   > ⚠️ مسیر دقیقاً باید `.github/workflows/` باشد. پوشه‌ی `workflows/` در ریشه‌ی ریپو **هیچ اثری
   > ندارد** و GitHub آن را اجرا نمی‌کند.
2. در ریپو: **Settings → Pages → Build and deployment → Source** را روی **GitHub Actions** بگذارید.
   (اگر از workflow استفاده نمی‌کنید، همان «Deploy from a branch» کافی است — فقط شاخه `main` و
   پوشه `/docs` انتخاب شده باشد، نه `/root`؛ انتخاب root همان علت صفحه‌ی سفید بود.)
3. بعد از merge، تب **Actions** را چک کنید؛ پس از سبز شدن workflow، سایت روی
   `https://<user>.github.io/<repo>/` بالا می‌آید.

نکته‌ی زیرمسیر: چون سایت زیر `/<repo>/` سرو می‌شود، هیچ مسیر مطلقی (`/sw.js`, `/manifest.webmanifest`, …)
نباید نوشته شود. `vite-plugin-singlefile` مقدار `base` را روی `./` قفل می‌کند و همه‌ی JS/CSS را داخل
`index.html` درون‌خطی می‌کند؛ بقیه‌ی آدرس‌ها (manifest، آیکون‌ها، ثبت service worker) هم نسبی شده‌اند.

برای تست محلی: `npm run build && npm run preview`.

### صدای بی‌درز بدون فایل صوتی

`lib/ambient.ts` به‌جای پخش فایل، صدا را می‌سازد. بافرِ نویز با «دو پاس عبور از فیلتر و
انتقالِ وضعیتِ فیلتر» تولید می‌شود؛ چون تمام قطب‌های فیلترِ رنگی (صورتی/قهوه‌ای) داخل دایره‌ی
واحدند، وضعیتِ فیلتر در پایانِ بافر عملاً به وضعیتِ ابتدای آن برمی‌گردد، یعنی سیگنال *دقیقاً*
دوره‌ای است و `loop = true` هیچ کلیک یا درزی ایجاد نمی‌کند. علاوه بر آن، بافرها بلندند
(۱۲ تا ۲۰ ثانیه) و چند LFO کُند، طیف و بلندی را پیوسته تغییر می‌دهند تا گوش الگوی تکراری
پیدا نکند. رعد و برق هم یک رویدادِ زمان‌بندی‌شده‌ی تصادفی است (با پاکتِ حمله/فرود و جاروبِ
فیلتر)، نه یک لوپ. تست‌ها هم همین «پیوستگی در نقطه‌ی loop» را اندازه می‌گیرند.


### دروس نمونه و به‌روزرسانی بدون تکرار

- نمونه‌های قبلی حفظ شده‌اند؛ **قلب، غدد، کلیه، روماتولوژی، خون، گوارش و ریه (هاریسون)** و
  **رادیولوژی (هرینگ)** با مباحث قابل ویرایش در فهرست هستند. این‌ها سرفصل‌های پیشنهادی مطالعه‌اند،
  نه فهرست دقیق یک ویرایش خاص؛ زمان و حجم‌ها هم تخمینی‌اند.
- از «برنامه ← دروس» یا «تنظیمات ← داده‌ها»، نمونه‌ها را دوباره اضافه کنید: فقط درس‌ها و مباحث
  جاافتاده/جدید افزوده می‌شوند. شناسهٔ محلی، نام و رنگ ویرایش‌شده، پیشرفت، یادداشت و زمان‌های
  شخصی قبلی بازنویسی نمی‌شوند.
- `sampleId` روی درس و مبحث، هویت نمونه را مستقل از نام نگه می‌دارد. برای داده‌های قدیمیِ بدون این
  کلید، نام نرمال‌شدهٔ فارسی/عربی و نام‌های قدیمیِ شناخته‌شده (مثل «قلب» و `Heart Failure`)
  تطبیق داده می‌شوند. شناسه‌های کاتالوگ را هنگام تغییر عنوان یا ترتیب عوض نکنید.
- اگر نسخه‌های قبلی از قبل موارد تکراری ساخته‌اند، این به‌روزرسانی آن‌ها را خودکار حذف/ادغام
  نمی‌کند، چون ممکن است هرکدام سابقهٔ مطالعه داشته باشند؛ اما بارگذاری دوباره تکرار تازه نمی‌سازد.
- دکمهٔ متنی «افزودن درس» همیشه در فهرست پُر در دسترس است؛ نمونه‌ها هیچ محدودیتی برای درس‌های
  دلخواه ایجاد نمی‌کنند. فهرست بلند مباحث نمونه ابتدا بسته است و با کلیک روی عنوان باز می‌شود.

### مطالعه بدون درس

در صفحهٔ مطالعه، «مطالعه بدون درس» را انتخاب کنید و تایمر آزاد یا پومودورو را شروع کنید.
در کتابخانهٔ خالی هم نیازی به ساختن درس/مبحث نیست. این جلسات با `topicId: null` و `rating: null`
ذخیره می‌شوند؛ زمان خالص، XP زمانی، تداوم مطالعه و آمار را افزایش می‌دهند، ولی مبحث، تسک یا مرور
مصنوعی نمی‌سازند. توقف/ادامه، جابه‌جایی صفحه، بازکردن دوبارهٔ اپ و Backup/Restore همچنان کار می‌کنند.

### نویز قهوه‌ای و پس‌زمینه‌ها

نویز قهوه‌ای یک لایهٔ مستقل و یکنواخت در میکسر است و با صداهای طبیعت ترکیب می‌شود. در ارتقای
داده‌های قدیمی، حجمش **صفر** است تا ترکیب ذخیره‌شده ناخواسته عوض نشود؛ با کلید «نویز قهوه‌ای»
یا پریست «تمرکز بم» روشنش کنید. حجم هر لایه و حجم کلی ذخیره می‌شود، ولی پخش بعد از رفرش خودکار نیست.

پس‌زمینهٔ هر صفحه (و هر زیرصفحهٔ برنامه) از SVGهای محلی با لبه‌های حجمی، سایهٔ نرم و نور محو
ساخته شده است. بدون فایل تصویری خارجی، انیمیشن یا مصرف مداوم پردازنده؛ در موبایل محوتر است و
ستون محتوا خوانا می‌ماند. با تم روشن/تیره و رنگ انتخابی هماهنگ است و از تنظیمات با کلید
«گرافیک پس‌زمینهٔ صفحه‌ها» خاموش می‌شود. تصاویر تزئینی کلیک را نمی‌گیرند و از صفحه‌خوان پنهان‌اند.
